VERTEX — фитнес-клуб
Веб-сайт фитнес-клуба VERTEX предназначен для знакомства с направлениями клуба, выбора абонемента и управления пользовательскими данными. Сайт выполнен на HTML, CSS и JavaScript и запускается непосредственно из локальной папки — без сборки, установки пакетов и внешних библиотек.
Возможности сайта
- Главная страница — информация о клубе, направлениях тренировок и навигация по разделам.
- Абонементы — тарифы на 1, 3 и 12 месяцев. Для годового тарифа предусмотрена скидка 25%.
- Регистрация и вход — создание аккаунта и авторизация пользователей.
- Личный кабинет — просмотр статуса абонемента и уведомлений.
- Оформление абонемента — демонстрационная операция с добавлением записи в историю продаж. Реальная оплата не выполняется.
- Вакансии — просмотр предложений и отправка отклика через форму.
- Панель администратора — управление пользователями, просмотр сводных показателей и отчётов по продажам, экспорт данных в CSV.
- Несколько языков — русский, казахский и английский. Панель администратора доступна на русском языке.
- Адаптивный интерфейс — отображение сайта на компьютерах, планшетах и смартфонах.
Требования к системе
При разработке сайта учитываются следующие требования:
1. Простота использования. Структура сайта и элементы управления должны быть понятными для посетителей.
2. Быстрая запись на тренировки. Клиент должен иметь возможность без лишних действий выбрать подходящее направление и записаться на тренировку.
3. Удобный интерфейс. Дизайн должен быть аккуратным, современным и удобным на разных размерах экрана.
4. Стабильная работа. Основные функции сайта должны работать корректно и быть доступны пользователям.
5. Управление пользователями. Администратор должен иметь возможность просматривать и изменять данные пользователей.
6. Защита данных. Персональная информация и учётные данные пользователей должны быть защищены от несанкционированного доступа.
7. Работа при высокой нагрузке. Архитектура системы должна предусматривать возможность обслуживания большого количества пользователей.
8. Кроссплатформенность. Сайт должен корректно открываться в современных браузерах на компьютерах, планшетах и смартфонах.
9. Уведомления. При возникновении ошибок или других важных ситуаций пользователь должен получать соответствующее уведомление.
10. Качество реализации. Программный код должен быть понятным, структурированным и удобным для дальнейшего сопровождения.
11. Безопасный вход. Процесс авторизации должен предусматривать проверку учётных данных и защиту пользовательских аккаунтов.
12. Быстрое формирование отчётов. Администратор должен иметь возможность оперативно получать сводную информацию и отчёты о продажах.
Перечисленные пункты описывают требования к системе. Текущая версия реализует интерфейс и демонстрационные сценарии на стороне браузера; для полноценной эксплуатации необходима серверная инфраструктура и дополнительные механизмы защиты.

Запуск
1. Скачайте или распакуйте папку проекта на компьютер.
2. Откройте файл index.html в современном браузере, например Google Chrome, Microsoft Edge или Firefox.
Сборка и установка дополнительных пакетов не требуются. Для сохранения данных браузер должен поддерживать и разрешать LocalStorage.

Хранение данных и ограничения
Сайт сохраняет данные в LocalStorage браузера на текущем устройстве. Это относится к аккаунтам, абонементам, истории продаж, уведомлениям и откликам на вакансии.

В текущей версии:
- отсутствует серверная часть и общая база данных;
- данные не синхронизируются между устройствами и браузерами;
- авторизация является демонстрационной и не обеспечивает уровень защиты полноценной серверной системы;
- оформление абонемента не списывает деньги и не подключено к платёжному шлюзу;
- доступность сайта и производительность при высокой нагрузке не гарантируются.
Не вводите настоящие пароли, платёжные реквизиты и конфиденциальные персональные данные.
Сброс данных
Чтобы удалить данные VERTEX из текущего браузера и восстановить начальные демонстрационные аккаунты:
1. Откройте сайт и нажмите F12.
2. Перейдите во вкладку Console.
3. Выполните следующий код:
Object.keys(localStorage)
  .filter(function (key) {
    return key.indexOf('sv_') === 0;
  })
  .forEach(function (key) {
    localStorage.removeItem(key);
  });

location.reload();
Сброс удалит сохранённые в этом браузере аккаунты, продажи, отклики и другие данные VERTEX.

Чтобы заменить изображения направлений, поместите новые файлы в папку images/, сохранив следующие имена:
- fitness.jpg
- yoga.jpg
- boxing.jpg
- crossfit.jpg
- swimming.jpg
- strength.jpg
После замены обновите страницу в браузере.
