# VERTEX — фитнес-клуб

Учебный веб-проект фитнес-клуба VERTEX. Это одностраничный сайт на HTML, CSS и JavaScript без сборки и внешних библиотек: страницы открываются из локальной папки, а данные демо-приложения сохраняются в браузере.

## Возможности

- Главная страница с направлениями клуба и адаптивной навигацией.
- Единый абонемент на 1, 3 или 12 месяцев; на годовой тариф заложена скидка 25%.
- Регистрация, вход и личный кабинет со статусом абонемента и уведомлениями.
- Демо-оформление абонемента: операция записывается в историю продаж, но реальные платежи не принимаются.
- Страница вакансий с формой отклика.
- Панель администратора: управление пользователями, сводные показатели, отчёты по продажам и экспорт CSV.
- Интерфейс на русском, казахском и английском языках. Панель администратора доступна на русском.
- Изображения для карточек направлений лежат в папке `images/`.

## Запуск

1. Скачайте или распакуйте проект на компьютер.
2. Откройте файл `index.html` в современном браузере, например Google Chrome.

Сборка, установка пакетов и подключение к интернету для базового запуска не требуются. Для сохранения аккаунтов и данных браузеру нужен доступ к `LocalStorage`.

## Демо-аккаунты

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `admin123` |
| Клиент | `client` | `client123` |

Это общедоступные демонстрационные учётные данные. Не используйте их для реальных аккаунтов.

## Данные и безопасность

Проект предназначен для демонстрации интерфейса. Пользователи, пароли, абонементы, продажи, уведомления и отклики хранятся в `LocalStorage` текущего браузера на текущем устройстве. Серверной части, защищённой авторизации и платёжного шлюза нет. Не вводите настоящие пароли или персональные данные.

Чтобы сбросить данные VERTEX и восстановить начальные демо-аккаунты, откройте инструменты разработчика браузера (`F12`), перейдите в Console и выполните:

```js
Object.keys(localStorage)
  .filter(function (key) { return key.indexOf('sv_') === 0; })
  .forEach(function (key) { localStorage.removeItem(key); });
location.reload();
```

Сброс удалит созданные в демо-проекте аккаунты, записи о продажах, отклики и другие данные VERTEX в этом браузере.
